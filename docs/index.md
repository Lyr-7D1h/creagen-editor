# What is Creagen?

Creagen is the naming used for both a creative coding javascript library and an open source creative coding web editor in which you can you the Creagen library but also many other libraries to write creative code in the browser.

## Creagen Editor
The editor is focused on being minimal, hackable, fast, and powerful.

Its goal is to make creating and sharing creative projects as easy as it possibly can be.

**Notable Features:**
- Custom version management tailored for sketches and iterations and shareability
- Npm package and types resolution
- Easy and customizable shortcuts
- Easy and customizable settings
- Sketch parameterization (See [Parameters](https://creagen.dev/docs/editor/parameters))
- Remote control of sketches (See [Controller](https://creagen.dev/docs/editor/controller))
- Supports local builds (See [Usage](https://creagen.dev/docs/development/usage))
- Download generated images and svgs
- Fullscreen mode for a more live-coding like setup

## Creagen Library

The library is focused on having a clean and easy to use API to create visual output in the web while also providing enough utility and performance for doing calculations and mathematics.
